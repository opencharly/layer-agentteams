# 2026.269.1323 — feat: relocate the agentteams pod + snapshot check beds from opencharly/charly

## Summary

Relocate the AgentTeams R10 check beds on the **pod** substrate (and the boxes they deploy) from `opencharly/charly`'s `charly.yml` into this repo, which OWNS the artifacts the beds test. A check bed must live in the repo that owns what it tests: the bed runner's dev-tree override (`proc.SelfSuperprojectOverridePair`, `spec/proc/repo_override.go`) points the bed project's own superproject's `@github` refs at the local tree. In the umbrella every submodule's superproject is `opencharly/opencharly` (which hosts no candies), so a candy owned by another repo was never exercised as in-development code while its bed sat in `charly`. Relocated here, the bed composes the LOCAL candy with no `@github` pin.

This is a successor PR to the auto-closed `opencharly/layer-agentteams#5` (closed by the validator's runaway guard after the body stayed frozen against an older head). This branch is fresh, all findings from those BLOCK verdicts are fixed, and the body is final at push.

### The three CalVer-shaped values are different KINDS of value (they are not meant to reconcile)

The run directory `.check/check-agentteams-pod/<calver>/` is not a version. It is a wall-clock timestamp minted at invocation. The check-plugin's own formatter documents this — `plugin-check/candy/plugin-check/calver.go`:

```
// The AI-harness + bed runner tag their artifacts (image build tags, check-run
// dirs, deploy aliases, result-<calver>.yml, NOTES.md headers) with "what time is
// it NOW" in the canonical fixed-width CalVer form. ...
func ComputeCalVer() string {
	return ComputeCalVerAt(time.Now().UTC())
}
```
